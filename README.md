# 华中农业大学 · 校园运动场馆预约系统

一个**纯前端应用**：无需安装依赖、无需构建，直接用浏览器打开 `index.html` 即可使用完整流程。
所有数据保存在浏览器本地存储（localStorage）中；系统初始只预置一个超级管理员账号和三条场馆须知通知，其余内容（学生账号、预约、帖子、组队）都由使用者自行产生。

## 一、如何预览

方式一（最简单）：双击打开 `index.html`。
（直接双击也能正常使用，但部分浏览器在 `file://` 下禁用本地存储，刷新后数据会重置；想保留数据请用方式二。）

方式二（推荐，http 方式运行）：

```powershell
cd "C:\Users\XDDN\Documents\ChatGPT\运动预约"
py -m http.server 8123
```

然后浏览器访问 <http://localhost:8123/>。

## 三、已实现的流程

**1. 场馆与时段**
- 场地清单：羽毛球馆 20 片（东体育馆3楼）、排球老场 8 片（第二运动场）、排球新场 6 片（第三运动场）、排球室内场 1 片（西体育馆）、乒乓球馆 36 张（东体育馆1楼）、室内网球馆 3 片（东体育馆2楼）、室外网球场 4 片、游泳馆男/女各 1 个（东体育馆游泳馆）。
- 每个场地有编号（如 `羽03`、`乒12`、`排01`）、所在位置、运动图标。
- 时段 08:00 - 22:00，每小时一个时段，共 14 个时段；仅可预约**本月内**日期。

**2. 预约与图标状态**
- 绿色「可约」→ 点击后填写预约理由即可提交；蓝色「我的」→ 查看/取消自己的预约；橙色「待审」→ 已提交等待管理员审核；灰色「已约」→ 已被占用；浅灰「—」→ 时段已过期。
- 红色斜纹「冲突」→ 你在该时段已预约了其他场馆：同一时段只能占用一个场馆，需先取消原预约，其他场馆才能预约或组队。
- 过期记录自动清理：活动时间已过且**超过 7 天**的预约会被自动删除，不再出现在「个人主页 → 我的预约」和管理员「待审核预约」中。
- 「个人主页 → 我的预约」与组队、后台待审核队列一样**按活动时间排序**：越接近当前时间的排越前（今天 → 明天 → 后天…），已过期的排在最后并按时间倒序。
- **中英文切换**：顶部导航右侧（登录页右上角也有）的「EN / 中文」按钮可随时切换界面语言，选择结果保存在浏览器本地，刷新后仍生效。切换范围包含导航、页面标题、按钮、表头、状态标签与提示语；场地编号在英文下显示为 `BD01 / VB03 / TT12 / TN02 / SW01`。
- **通知自动翻译**：英文模式下，预置的场馆通知用内置词典即时翻译；管理员新发布的中文通知会调用在线翻译接口转成英文（结果缓存在浏览器本地，之后瞬间显示）。**未翻译成功时显示中文原文**，不会出现中英混杂。用户自己输入的帖子、预约理由、姓名等始终保持原样。
- **红点提醒**：以下情况会在顶部导航「个人主页」及个人主页对应标签上显示红点——
  - `我的预约`：管理员通过 / 拒绝我的预约
  - `我的帖子`：别人评论、点赞、收藏我发的帖子
  - `我的好友`：有人给我发好友申请，或**我发出的好友申请被对方同意**
  - `我的组队`：我参与（或我发起）的组队状态变化（入队被同意、队长提交预约、预约被取消等）
  - `顶部导航·组队`（队长视角）：有人申请加入我发起的队伍、有人**撤销**入队申请，或已入队的成员退出我的队伍 —— 进入「组队」页导航红点即消失，但该队伍「管理队伍」按钮上的红点会保留，点到该队伍的管理按钮（弹窗「最近动态」里能看到谁申请、谁撤销、谁退出）才消失
  红点分两层：**顶部导航「个人主页」上的红点表示“有新消息”**，打开个人主页（或点击任一标签）即消失；**各标签自己的红点表示“这个标签有更新”**，需要点进该标签才消失（`我的预约` 是默认标签，打开主页即视为已查看）。之后再发生新变化会重新提示。

**3. 预约方式**
- 直接预约：不再区分个人 / 社团，选好场地与时段后填写**预约理由**（必填）即可提交；同行成员选填，**人数不做任何要求与限制**。
- 组队模式：想凑人时发布组队消息，同学申请加入 → 队长同意 → 人数凑齐后队长提交预约（自动以队伍标题作为预约理由）。成员可随时退出：**申请未被同意时可随时撤销申请**；**已被同意入队的成员可退出队伍**，队长会收到红点提示与「某某退出了队伍」的动态消息（队伍已提交预约时，需队长先取消预约才能退出）。活动时间已过的组队会**置灰并标注「已过期」**，队长与成员均不能再申请、同意、退出或提交预约；**过了活动当天 24 点（第二天起）整条组队消息自动删除**，组队模块不再显示。
- 队长可在「管理队伍」里**修改需要人数**：不能少于当前已加入人数，最多 15 人（人数达到时队伍自动变为「人数已满」，取消预约后方可继续修改）。
- 队长还可在「管理队伍」里把**已同意入队的队员移出队伍**：被移出者不再计入队伍人数、不能再申请加入该队；他的「我的组队」里该队伍状态显示为**红色「您已被移除队伍」**，同时个人主页导航与「我的组队」标签亮红点（点进去后清零）；队长端的「最近动态」会记录「某某 被移出队伍」。
- **邀请好友组队**：队长可在队伍卡片上点「邀请好友」，从好友列表里直接邀请（已入队 / 已被移出 / 已邀请的好友显示对应状态且不可重复邀请）。被邀请的好友在「个人主页 → **申请组队**」看到邀请并可**同意 / 拒绝**；同意后即加入队伍、队长端会看到「对方已同意」，拒绝则显示「对方已拒绝」。邀请与回应都会给对应用户的**个人主页导航 + 申请组队标签**亮红点，点进该标签后清零，之后再变化会重新提示。**被移出队伍的用户既不能被再次邀请、也不能自己申请加入。**
- **组队预约撞车时的补救**：队伍满员后提交预约时，若该场地该时段已被他人预约，会弹出「重新安排场地」：提示「该时间段该场地已经有人预约」，并列出**同一时段的其它空闲场地**（点一下即可用新场地直接提交预约）；若该时段已无空闲场地，则提示「该时间段已无合适场地可预约，请更换时间段」，并提供**更换日期 + 更换时段**表单，队长改完即可提交。
- **解散队伍**：队长可在「管理队伍」里点「解散队伍」（需二次确认）：队伍即从组队模块消失，**队长与已入队成员**都会在「个人主页 → 我的组队」看到该队伍状态为「**队伍已解散**」，并且**个人主页导航 + 我的组队标签**亮红点（打开个人主页熄导航红点、点进「我的组队」熄标签红点）；已提交预约的队伍需先取消预约才能解散。
- 组队列表**按活动时间排序**：越接近当前时间的排越前（今天 → 明天 → 后天…），已过期的排在最后；支持**「我的组队」筛选**（只看我发起或已申请加入的队伍）与**活动日期筛选**，默认显示全部，可一键清除，筛选条件同步在地址栏 `#/teams?mine=1&teamDate=YYYY-MM-DD`。

**4. 交流中心**
- 管理员通知置顶显示，最多 3 条；更早的通知收进「历史通知」（在通知标题右侧点击查看）。用户可发帖、评论、点赞、收藏、举报、加好友。
- 点击交流中心里帖子/评论的**头像或昵称**、以及组队页的**成员姓名**，都会弹出对方主页（资料 + 好友数/预约数/帖子数），可在弹窗里直接**加好友**；已是好友、已发送申请、或对方已申请你时，会显示对应状态提示。
- 对方主页底部按关系给出操作（都会先弹确认框）：**好友**→ 删除好友 / 拉黑好友；**非好友**（含已发申请、对方已申请）→ ＋ 加好友 / 拉黑。删除后对方从「我的好友」消失、可重新添加；拉黑后对方同样消失，且**对方无法再添加你**（会提示「您已被对方拉黑，不能加好友」），自己这边可以在同一弹窗**解除拉黑**。
- 加好友需对方同意；被举报内容可由管理员处理。

**5. 个人主页**
- 姓名、年龄、年级、专业、班级、爱好、个人介绍、头像（本地图片上传）、性别；可查看我的预约 / **我的组队** / 好友 / 帖子 / 收藏。
- 「我的组队」列出**本月**我发起或参与的全部组队（含已从组队模块移除的历史组队），按活动时间排序（越接近当前时间越靠前，已过期排最后），并标注我的身份（发起人 / 已加入 / 待队长同意）与队伍状态。

**6. 管理后台**
- 预约审核（通过 / 拒绝）、举报处理（驳回 / 警告 / 删除帖子 / 禁止发帖 / 封禁账号 / 解除限制）、通知发布、数据概览。待审核队列**按活动时间排序**（越接近当前时间越靠前，已过期排最后）；其中**活动时间已过**的预约会置灰并标注「已过期」，管理员不能再对其通过或拒绝。
- 被封禁用户**仍可正常预约场馆**，但不能发帖、评论、加好友。

## 五、下一步建议（正式版的迭代方向）

> 正式版方案已单独成文，见 `docs/` 目录：
> - `docs/后端接口与数据库设计.md` —— 架构、13 张表结构、REST 接口清单、认证与权限矩阵、防超卖方案、前端迁移步骤、实施路线图
> - `docs/schema.sql` —— 可直接执行的 MySQL 8 建表脚本（含 9 类场馆 + 80 个场地的 seed，已在本机 MySQL 8.0 实测通过）

- 后端与数据库：把 `store.js` 中的规则迁移到服务端（用户、场馆、时段、预约、组队、帖子、举报、通知表），前端改为调用 API。
- 并发与超卖控制：预约提交时用数据库唯一约束/事务锁定「场地 + 日期 + 时段」，避免同一时段被重复预约。
- 权限与安全：密码加盐哈希、登录态（JWT/Session）、管理员初始密码随机化并强制首次修改、操作日志。
- 消息通知：好友申请、入队申请、预约审核结果的站内消息或微信/短信提醒。
- 校区规则细化：按场馆配置可提前预约天数、每人每日预约上限、场馆开放时段差异等。
